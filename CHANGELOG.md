## [0.1.0] - 2026-05-08

### Added Big Number library with parsing, formatting, arithmetic, and Unity editor integration.

- Initial implementation of BigNumber struct with support for large numbers using mantissa/exponent representation.
- BigNumberParser for parsing from strings with various suffixes and formats.
- BigNumberFormatter for formatting BigNumbers into human-readable strings with different styles.
- BigNumberPropertyDrawer for Unity editor to display BigNumbers in the inspector with foldout for mantissa/exponent.
